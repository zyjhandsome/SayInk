# UI 与交互优化记录（2026-10-18）

本轮在已有工作区改动上完成 UI-01 至 UI-09，不改导航顺序、识别模型选择和数据存储规则。

| 评估编号 | 完成内容 | 验证 |
| --- | --- | --- |
| UI-01 | 会议开始卡正文与实时笔记区可滚动，开始、暂停、继续与结束操作位于滚动区外。 | 真实会议控制器覆盖浏览、开始、录制、暂停及整理状态；910×472 可用区域下窗口及主要操作完整可达，检查 100%/150% 缩放和中文字体。 |
| UI-02 | 实时文字稿仅在内容变化时重绘，保留选区和滚动位置；用户停在底部且未选字时跟随新发言。 | 追加真实临时数据库中的片段并触发会议刷新，选中内容不变，滚动位置由 60 保持为 60；另覆盖底部跟随。 |
| UI-03 | 侧栏显示本场会议音源、录制/暂停/整理状态及会议保存去向，切页保持，结束后恢复转写配置提示。 | 覆盖混合音源、切到通用页、模型状态刷新、暂停/继续与会议结束。 |
| UI-04 | Ctrl+F 在会议列表中搜索会议，在进行中打开本场文字稿查找；Enter 下一处并循环。 | 实际键盘事件验证不会切到转写历史；验证匹配、无匹配及循环查找。 |
| UI-05 | 搜索无结果显示数量、说明和清除按钮，隐藏旧详情；保存草稿失败时保留原记录、草稿和搜索条件。 | 覆盖无匹配、清除后恢复、旧标题占位清理及保存失败。 |
| UI-06 | 会议可手动暂停与继续。暂停停止新音频采集，已录内容继续识别，继续时仍是同一场会议。 | App 编排回归验证停止采集、保持会议 ID、禁止自动恢复、主动继续及暂停后结束；物理设备行为未实测。 |
| UI-07 | 默认状态使用「说话人区分已增强/较粗略」，模型与语音分段诊断移入悬停详情。 | 原生深浅主题预览及状态文案回归。 |
| UI-08 | 精简首次欢迎，优先解释模型准备、按键试用和结果位置；跟随实际音源、输出方式、快捷键及 Esc 偏好。 | 覆盖缺模型下载入口、电脑声音、仅存历史但历史关闭、定制快捷键及禁用 Esc。 |
| UI-09 | 更新 docs 中的六页深浅主题截图，补充真实会议控制器驱动的录制、暂停、查找、小屏及无结果预览。 | 根目录 24 张、会议目录 34 张原生预览；150% 会议预览位于 build/ui-optimization/meeting-150。 |

## 验证结果

- 全量回归：1621 通过，1 跳过，0 失败。跳过项需要另外指定真实 Silero 模型目录，未使用开发者个人模型目录代替隔离环境。
- 全项目 Ruff 与差异空白检查通过。
- 最后统一查找栏样式后，补跑会议交互与 UI 样式回归；结果见 build/ui-optimization/verification.json。
- 全量测试记录：build/ui-optimization/test-results.xml。
- 小屏和文字稿刷新复现采用真实 PyQt6 控件、中文字体及临时会议数据库，包含 100%/150% 缩放。

这些检查不代替真实麦克风、跨应用粘贴、真实读屏器和用户可用性测试。本轮更新源码和预览，未重新生成安装包。
