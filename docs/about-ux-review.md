# 关于页与录音提示优化（2026-10-18）

针对「关于」页截图完成定向优化，保留品牌、导航顺序、主题、字号及既有录音机制。

## 界面与行为

- 「应用与更新」独立成组，当前版本使用普通文本；检查按钮展示操作，旁边显示检查状态及上次检查时间。
- 自动检查说明与实现一致：启动时检查，距离上次检查至少 24 小时，不自动下载。
- 「当前配置」用固定标签列和靠近标签的值展示识别模型、快捷键、音源、录制方式、输出去向和文字润色。模型、快捷键、润色分别提供明确的设置入口，并同步主导航选中态。
- 关于页内容最大宽度为 760 逻辑像素，保持默认窗口内的主要信息可见。移除重复的快捷键说明卡片；完整操作说明保留在通用页，快捷提示保留在侧栏。
- 文件位置独立为可折叠区域，整行可点击，支持键盘和清楚的焦点边框。原生展开图标按当前主题重新着色，完整路径可选择、复制并换行。
- 侧栏、配置摘要及通用页共用录音提示规则：采集电脑声音时使用「按住录制」，持续转写明确说明启动后可以松开；Esc 关闭时不再提示 Esc 停止。
- 输出提示遵循实际输出设置，包括手动覆盖。仅记录历史但历史关闭时显示明确警告，不声称结果已被保存。
- 提示刷新使用独立信号，不触发音频重新配置，不中断录音或清空待处理语音。
- 更新下载期间重新打开关于页会恢复进度；下载失败的原因保持可见，重新检查后清除旧失败状态。下载中重复检查不会启动另一个检查任务。后台检查过程中打开关于页后，后续失败会解除检查中的禁用状态。

## 验证方法

使用 Python 3.10 和原生 PyQt6 控件，结合自动化交互与图片检查验证。新增回归覆盖音源和输出组合、历史关闭、Esc 偏好、设置跳转、键盘展开、主题切换及更新按钮状态。

离线预览工具：

```powershell
python tools/capture_about_ui.py --output build/about-ux-review/preview-100
$env:QT_SCALE_FACTOR = '1.5'
python tools/capture_about_ui.py --output build/about-ux-review/preview-150
```

工具使用临时设置和虚构历史，屏蔽凭据、开机自启注册表、音频设备枚举和模型加载，不发起网络请求。每种缩放生成深浅主题下的默认、电脑声音、历史关闭、持续转写、更新失败、下载中、窄窗口及展开文件位置预览。

检查包含默认 960×640 与窄窗口 880×580、100% 与 150% 缩放。主要信息在默认窗口内完整显示；窄窗口及展开路径采用纵向滚动，长路径保持换行。
