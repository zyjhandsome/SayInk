# SayInk Codex 式主窗口

Date: 2026-09-21  
Status: approved  
Approach: 3, 先整壳和语言，页内控件复用后收成行  
Supersedes: `docs/superpowers/specs/2026-09-19-island-ui-redesign-design.md`

## Problem

SayInk 仍是顶部空间岛：胶囊、设置岛、历史岛。岛的 28px 大圆角、蓝描边卡片、三个等权按钮，和 Codex 式桌面工具的安静密度不是一套语言。用户要的是完整窗口（侧栏 + 主工作面），不是再打磨一次岛。

## Goal

在不改转写链路的前提下，用一个 Codex 气质的主窗口收纳历史和设置；听写只留一条薄状态条。视觉几乎无彩色强调。启动和退出习惯仍是托盘工具。

## Non-goals

- 不改热键、录音、VAD、识别、粘贴、润色、历史 SQLite、配置键名。
- 不把主窗口做成系统原生标题栏应用（自绘顶栏，关窗藏托盘）。
- 不引入 Geist/Inter 等 Web 字体。
- 不把听写条做成第二个主窗口，不恢复展开岛上的「历史 / 设置」按钮。
- 不把侧栏改成会话列表（threads）。侧栏只做五个导航。
- 不新增第五个设置页，不保存或回放音频。
- 不实现 Codex 的主题 JSON / contrast 滑杆；只做浅 / 暗 / 跟随系统。
- 不重写模型下载、测麦、LLM 测试的状态机，只改层级和样式。

## Design read

Windows 托盘型桌面工具，打开后像 Codex 的设置+历史工作台。刻度：安静、紧凑、近无彩。动效只服务听写状态。

## Architecture

```
app.py（编排不变）
  ├── MainWindow          侧栏 + 齐平主面（取代 SettingsWindow / HistoryWindow 岛）
  │     ├── 历史
  │     ├── 通用 / 引擎 / 润色 / 关于
  │     └── 复用 TriggerModePicker、AudioSourcePicker、ModelCard、HotkeyEdit…
  ├── ListenBar           FloatingWindow 收成薄条
  └── TrayIcon            状态词不变；双击打开 MainWindow
```

`SettingsWindow` 与 `HistoryWindow` 不再作为独立岛出现。其页面与信号迁入 `MainWindow`。`island_chrome.py` 的 720×640 sheet / 顶栏 pill / 顶部居中大岛定位删除；听写条用自己的窄条几何。

### Window lifecycle

- 启动：只进托盘，不弹主窗口。
- 托盘「打开 SayInk」、Windows 双击托盘：显示主窗口。进程内记住上次所在页；冷启动第一次打开落在 **通用**。
- 托盘「历史」：打开主窗口并切到历史。
- 关主窗口（顶栏 × 或系统关闭）：隐藏到托盘，不退出。退出只走托盘「退出」。
- 主窗口不是 Tool、不置顶。听写条是 Tool、置顶、不抢焦点。
- 听写条在采集开始时出现；结束 / 失败后按现有超时消失。

### Signals and data

主窗口继承现有设置信号：`settings_changed`、`theme_changed`、`hotkey_updated`、`hotkey_capture_started` / `ended`、`models_changed`、`auto_start_changed`、`sound_enabled_changed`。听写条继续发 `continuous_stop_requested`。配置键、历史库、转写编排不改。

不新增「上次所在页」配置键。只在当前进程记忆。

## Visual language

几乎无彩色强调。绿 / 红 / 琥珀只表示正在听、失败、警告。主按钮是 **ink 实心**（暗色白底黑字，浅色近黑底白字），不是蓝底。

### Surfaces

| Role | Dark | Light |
|------|------|-------|
| Window / sidebar / work surface | `#181818`（整窗同色齐平） | `#FFFFFF`（整窗同色齐平） |
| Hairline / divider | `rgba(255,255,255,0.08)` | `rgba(13,13,13,0.08)` |
| Selected nav / row | `rgba(ink, 0.06)` | 同公式 |
| Border / ring | `rgba(ink, 0.08–0.16)` | 同公式 |
| Secondary text | `rgba(ink, 0.40–0.55)` | 同公式 |

浅 / 暗 / 跟随系统都保留。暗色按近黑做；浅色是同一套 ink 叠加，不是现行冷灰蓝调。`design_tokens.py` 为唯一色轴；`design-system/MASTER.md` 必须与之对齐。Accent token 可保留给极少数焦点环，但默认控件、导航、主按钮、选中卡片都不得再铺实心蓝。

### Type, shape, space

- 字体：Segoe UI Variable → 微软雅黑 UI → Segoe UI。
- 侧栏 / 控件 12px，正文 13px。不用 22px 大标题。
- 控件高 28–30px。圆角：行 8–12px，听写条 / 开关 pill，主窗外框 12px。
- 主窗口约 **960 × 640**。侧栏 **160px**。侧栏与主面齐平，只靠一条 hairline 分开，无 inset 第二层卡片。
- 顶栏 36px：状态点 + 「SayInk」+ 最小化 + 最大化 + 关闭。关闭 = 藏托盘。最大化后内容跟着铺开，侧栏仍 160px。
- 动效只服务听写条圆点与波形。尊重「减少动态效果」：无脉冲 / 波形，高度变化立刻到位。
- 禁止：满屏实心蓝、着陆页大标题、装饰渐变、彩色侧栏。录音红和听写绿不进导航、不进主按钮。

## Main window chrome

五个导航，顺序固定：**历史 / 通用 / 引擎 / 润色 / 关于**。当前项淡 ink 底，无蓝条、无左侧色条。

选中导航切换右侧 `QStackedWidget`。设置仍自动保存，无页脚保存条。

## Pages

### 通用

三组，顺序不变：录音 → 音频 → 偏好。

- 录音：两行选择（连续口述 / 按住说话），选中为淡 ink 底，不是蓝描边大卡片。快捷键一行，等宽键帽。提示一句：按住约 0.30s 开始持续听；松开不结束；Esc 或听写条「结束」结束整场。
- 音频：三枚矮段（麦克风 / 电脑声 / 混合），选中 hairline + 淡底。混合仍出琥珀说明。主按钮「测试声音」为 ink 实心。设备仍藏在「手动选择」，默认自动。
- 偏好：主题三段（跟随系统 / 浅色 / 暗色）+ 开关（开机启动、提示音、恢复剪贴板、保存语音历史）。保留天数和最大会话数仅在历史开时出现。开关开 = 听写绿轨，关 = 灰轨。

### 引擎

- 当前模型一张安静卡：名、「当前」chip（ink 底，非蓝）、体积、能力 chip。
- 存储一行摘要 + 次要「更改位置」。
- 可下载 / 已下载卡同一解剖。每卡一个 ink 主按钮（下载或使用此模型）。删除是语义红次要。进度仍在卡内。不重写下载状态机。

### 润色

开关在最前。关：只留开关和「直接输出原文」。开：预览、API 字段、提示词。Key 默认掩码。显示 / 测试连接 / 恢复默认同一动作列宽。测试连接的成败写在字段下，不作为系统对话框主反馈。开着时「测试连接」是该页唯一 ink 主按钮。

### 关于

第一行：SayInk + 版本 chip。三行状态：当前模型、快捷键、润色开/关。模型目录和配置路径在折叠「文件位置」里。底注按当前触发模式，用次要文字，不用大琥珀条除非有真的警告。

### 历史

主面左右分栏（不是整窗再拆侧栏）。

- 标题 **历史**。搜索 placeholder：搜索转写内容。200ms debounce 保留。
- **导出** 是雾面次要（不叫「导出 Markdown」当蓝主按钮；导出字段集不变）。选中 1 = 该场；多选 = 批量。
- 左：日分组（今天 / 昨天 / `YYYY-MM-DD`）。行：`HH:MM`、一行预览、chip（来源 / 目标进程名 / 段数）。选中行淡 ink 底。
- 右：chip（来源 / 触发 / 模型）；正文是主体。润色 ≠ 原文时两块，标签 **原文** / **润色**。只有一种文本则不标。
- 有润色时主按钮 **复制润色**；否则 **复制原文**。无润色则复制润色不可用。成功用轻量内联提示，不弹系统对话框。
- 空：「还没有会话。完成一次转写后会出现在这里。」
- 搜索空：「没有匹配的转写。」
- 删除：确认，保留 8 秒撤销。清空全部：底栏危险次要，单独确认。

SQLite schema、保留策略、导出字段不改。

## Listen bar

文件：现有 `floating_window.py`，行为收成薄条。

默认约 360 × 40，pill。从左到右：状态点、波形（仅采集中）、状态词、ink「结束」。无来源 chip，无「历史 / 设置」。

有实时字时高度增到约 64，圆角 16px，多一行 13px 摘录（单行省略）。仍不是展开岛，没有第二行按钮。

`×` / 「结束」在监听中 = 结束整场（同 Esc）。空闲关闭 = 收起。点击条本身不打开主窗口。

### State table

| State | Shell | Color | Auto-hide |
|-------|-------|-------|-----------|
| 模型载入中 | 一行 + 副标题 | muted，无波形 | 否 |
| 正在听 | 薄条；有字则加摘录 | 绿 + 波形 | 否 |
| 录音中（按住说话） | 薄条 | 红脉冲 + 波形 | 否 |
| 正在识别 / 润色中 | 薄条；可一行摘录 | ink | 否 |
| 已输入 / 已就绪 | 薄条 | ink | 1.5–2.2s |
| 已复制 | 薄条 + 琥珀副标题 | ink | 2.2s |
| 失败 | 两行，语义红 | 红 | 5s |
| 已取消 / 已停止 | 薄条 | dim | 1s |

失败不得把窗口撑到接近 260px。长错误进 tooltip。

保留：持续模式就绪后不弹闲置「待开始」；短按热键不显示听写条；粘贴失败报已复制，永不报已输入。

现有信号保留：`continuous_stop_requested`。`update_partial_text` 只更新摘录行，不再把窗口变成三按钮岛。

## Tray

三种图标：

| Kind | Color | When |
|------|-------|------|
| 就绪 | ink 麦克风（暗色浅、浅色深），不是蓝 | idle、已输入、已停止 |
| 采集 | 红麦克风 | 正在听、录音中 |
| 注意 | 琥珀 | 现有 `flash_attention`，然后恢复上一类 |

托盘采集红、听写条点绿：故意如此。托盘从任务栏读「正在收音」。

菜单圆角 8。结构：

1. 禁用状态行：`SayInk - {状态}`
2. **打开 SayInk**（原「打开设置」）
3. 历史
4. 切换模型（空：暂无已下载模型）
5. 开机自启
6. 退出

状态词与听写条同一套：就绪 / 正在听 / 正在识别 / 润色中 / 模型载入中。禁止「加载中」配「模型载入中」，或「监听中」配「正在听」。

## Cross-cutting empty / error / busy

| Scene | UI |
|-------|-----|
| 模型载入中 | 听写条副标题 + 托盘「模型载入中」；热键忽略；其它错误不得覆盖 |
| 载入失败 | 红两行听写条；托盘回到就绪 |
| 未识别 / 太短 | 红两行，5s |
| 无法粘贴 | 已复制 + 琥珀副标题，永不已输入 |
| 润色失败 | 静默原文，听写条不报错 |
| 测麦失败 | 按钮下红字 |
| LLM 测试 | 字段下内联 |
| 减少动态效果 | 无脉冲 / 波形；听写条高度瞬变 |

验收：

1. 启动不弹主窗口；关主窗口进程仍在，托盘可用。
2. 浅 / 暗 / 系统切换后主窗口、听写条、托盘无需重启即换肤。
3. 侧栏只有五项，无设置岛 pill、无隐藏 SettingsSidebar 双导航。
4. 听写条主操作只有「结束」；有字时最多多一行摘录。
5. 历史标题是「历史」；左右分栏；详情元数据是 chip。
6. 主按钮与选中态不是实心蓝。就绪托盘图标不是蓝。
7. Windows 双击托盘打开主窗口。主题、听写条、托盘、README 测试保持绿。
8. 手工冒烟：冷启动等就绪 → 持续听写 + 摘录 → 结束 → 托盘打开主窗口切历史/引擎 → 切换浅暗。

## Risks

- `SettingsWindow` / `HistoryWindow` 被大量测试按独立 `QDialog` 构造。迁移时先抽页面再换壳，避免一次改爆所有 UI 测试。
- 现行测试断言蓝 `ACCENT`、岛圆角 28、标题「过去的话」、托盘「打开设置」。改断言与改外观同一任务。
- Token 漂移：先发布 ink 轴，再让 QSS 从 `activate()` 生成。
- 听写条从岛收成薄条时，几何与 `update_partial_text` 自动升高必须有测试，防止回归成展开岛。

## Implementation note

按方案 3：先交付主窗口壳、五栏导航、听写条、托盘开窗、近无彩 token；设置里的大选择卡片收成行，但不重写下载 / 模型 / 测麦 / LLM 状态机。`app.py` 只改窗口装配，不改转写编排。
