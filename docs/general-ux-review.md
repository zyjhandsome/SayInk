# 通用设置 UX / UI 优化（2026-10-18）

根据通用页截图的评审，在现有 PyQt6 界面上完成修改，保留工作区原有的公共识别、会议与关于页改动。

## 实现与评审对应关系

| 评审问题 | 实现 |
| --- | --- |
| 音源与结果去向分散、自动联动难以理解 | 「录音与输入」内相邻显示音源与结果去向。明确区分自动策略、固定输入光标、固定仅保存历史；两种固定选择跨音源切换和重启保持。当前实际去向就地展示。 |
| 配置文案误读为正在录音 | 改为静态的「音频来源」说明，明确电脑声音不包含麦克风、开始录音前不采集。测试采集单独显示正在测试。 |
| Esc 结束与取消后果混淆 | 按住录音说明「取消本次、不保留」；持续转写说明「结束后已录内容继续识别」。Esc 偏好仅在持续模式显示，侧栏和听写条同步，会议仍独立结束。 |
| 通用页混入大量低频设置 | 整理为录音与输入、识别、会议默认设置、应用与历史四组。语言与词汇直接展示，算法和模型诊断默认折叠。 |
| 术语先于功能、下载状态像禁用按钮 | 使用语音分段、自定义词汇、增强说话人区分等功能名称，算法名放在详情。已下载改为普通状态文字；下载操作仅在需要时出现。 |
| 关键说明与选中状态偏弱 | 关键行为使用较清晰的正文次级色；分组标题加大。选中卡片使用蓝色边框、浅底色与原生单选标记，保持整卡可点击和独立的键盘焦点。 |
| 音频测试缺少设备与音量反馈 | 展示设备选择方式；测试时显示实际打开的设备（包括成功回退的设备）和输入音量。反馈覆盖有声、无声、偏低、偏高、错误与混合输入降级；更换音源或设备清除旧结论。 |
| 自动保存与实际生效不清楚 | 识别区持续显示生效规则；等待本场结束与加载失败在高级区折叠后仍可见。显示会议继承的实际音源和识别模型，未下载的独立模型给出下一步。 |
| 历史、剪贴板选项依赖不明确 | 仅保存历史且历史关闭时，就地给出恢复按钮；仅历史模式禁用无作用的剪贴板恢复。名称改为保存转写历史，说明不保存音频。关闭新增历史后，已有数据的保留规则继续可见可调整，并说明清理时机和会议边界。 |
| 视觉层级与键盘操作 | 测试声音改为次要操作；收紧重复分割与无效留白。Tab 按视觉顺序跳过折叠和无关控件；主题选项只停在当前项，方向键可切换。 |
