# 术语规范

界面、无障碍说明、提示、日志、代码注释、测试说明与产品文档统一采用下列名称。

## 三种模式

| 名称 | 行为 | 入口 |
|---|---|---|
| **单次转写** | 录制一段话，结束录制后统一输出文字；默认按住快捷键录音、松开后输出 | 设置 → 通用选择，由快捷键开始 |
| **持续转写** | 启动后持续采集，按停顿或换人边界分段输出，直到主动结束；松开快捷键不结束 | 设置 → 通用选择，由快捷键开始 |
| **会议** | 记录整场讨论，支持说话人、文字稿整理、标记与会议纪要；文字不自动粘贴 | 会议页或托盘开始 |

模式选择、状态标签与帮助说明使用完整名称。“按住说话”“松开快捷键”“持续监听”只描述操作或采集状态。
会议独立于前两种模式的快捷键选择，不在转写模式选择控件里增加第三个快捷键选项。
持续转写与会议的片段内换人分析均依赖 CAM++ 实际加载，属于实验性能力。
三种模式共用短句空结果重试；单次转写仍在结束录制且全部片段处理完后统一输出。

## 相关用语

| 用语 | 含义 |
|---|---|
| **录音 / 录制 / 采集** | 获取声音的过程；不表示应用保存了音频文件 |
| **转写** | 将语音转换为文字的过程 |
| **文字稿** | 转写产生的文字内容，尤其用于会议的发言记录 |
| **转写历史** | 单次转写与持续转写保存的文本记录；会议在会议页单独管理 |
| **转写条** | 显示采集、识别、输出与会议状态的浮动条 |
| **文字润色** | 对转写文字进行可选的整理与修饰 |
| **会议纪要** | 根据会议文字稿生成的摘要、要点、决议与待办等整理结果 |
| **麦克风 / 电脑声音 / 混合音源** | 三种音频来源。电脑声音指系统正在播放的声音（环回采集）；代码里的 `input_source_label` 是唯一出处，设备行、历史标签、会议卡片一律复用。设备列表中的 `[系统回放]` 只是环回设备的类型标记 |
| **会议记录中 / 会议已暂停 / 正在整理会议** | 会议三个采集状态；托盘、侧栏、转写条共用 `MEETING_STATE_LABELS`，转写条因空间只显示「会议中 · 计时」 |
| **开机时自动启动** | 托盘菜单与设置页同名；两处是同一个开关，任一处切换另一处即时同步 |
| **高级识别设置** | 共享识别配置的实际入口（设置 → 通用 → 识别 → 高级识别设置）；模型卡与会议页引用该路径时用 `ADVANCED_RECOGNITION_PATH`，不再写「公共识别」 |

文本是否输入其他应用、是否保存历史，按各模式与输出设置分别说明。结果去向的三个选项是「自动（随音源切换）」「输入当前光标」「仅保存到历史」；侧栏、关于页和快捷键说明使用同一说法。说话人身份无法判断时使用“说话人待确认”。
翻译、语音识别模型名称与外部来源的原始标题按其本义保留。

## 兼容与维护

- 配置与数据库中继续使用既有的 `hotkey`、`continuous`、`meeting` 标识，分别展示为单次转写、持续转写、会议。
- Python 中既有的 `dictation`、`transcribe`、`transcription` 等技术标识与文件路径保持兼容；中文描述使用本规范。
- 更新模式相关文案时，同步检查设置、首次使用引导、主窗口、转写条、历史、模型说明、README 与相关文档中的表述。
