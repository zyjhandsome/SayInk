# SayInk 红蓝对抗与全项目压力验证 · 2026-11-12

**验收建议：暂缓发布当前工作区。** 本轮确认 **18 项**：5 项 P1、9 项 P2、4 项 P3。其中，错误的接口地址、损坏文字稿和导入线程销毁能使隔离进程异常退出；部分字幕会丢正文，未超过界面上限的文字稿也能冻结 UI。报告记录问题与复验条件，本轮未修改产品代码。

**基线：** `main` / `0db10d3`，包含验收开始时已有的 28 个改动或新增路径（包括文字稿、音视频导入和会议多选）。Windows 11 x64 10.0.26300、Python 3.10.11、PyQt6 6.11.0、sherpa-onnx 1.13.8。使用临时配置与 SQLite、合成语音、离屏 Qt 和隔离子进程。未读取或使用真实凭据、历史和音频，也未向模型服务发送请求。

## 对照、维护与复验顺序

- **已反证或未扩大结论：** 拒写时数据库没有半条记录；音视频导入烟测中源文件逐字节不变，未自动排队纪要，返回的转写段落不含声纹。回归套件验证了会议文字不会被转写历史清理删除；未做真实外部服务联调。合成句里的专名「张明」误识为「史章明」，两种容器结果一致；一个样本不足以评估准确率或归因给导入流程。
- **维护风险有具体接缝：** `MeetingPage.refresh` 同时加载、恢复选择、处理空库、刷新详情和处理编辑草稿（图谱认知复杂度 58）；`_on_selection_changed` 在批量分支还重复扫描复选状态。按「浏览 / 批量 / 导入」收敛页面状态与刷新入口，可直接消除 QA-10、QA-14 类冲突。文字稿预览、确认、控制器再次解析同一文本，合并成一次有版本标识的解析可降低 QA-04 的交互成本。URL 解析、显示、发送和记忆授权应使用同一个经过验证的端点对象，减少 QA-01、QA-12 和 QA-16 的分叉。
