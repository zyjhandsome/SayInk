## 方法与范围

| 维度 | 看什么 |
| --- | --- |
| 功能正确性 | 录音、识别、输出、会议开始/结束、纪要队列、说话人收尾是否按规格发生 |
| 逻辑与关联 | 状态互相覆盖、草稿与生成的时序、升级迁移与现行说明是否一致 |
| 一致性 / 清晰性 | 同一设置在侧栏、关于页、设置项、转写条、README 里的说法；错误是否说对原因 |
| 繁冗 | 只在确认会造成用户看不懂或维护分叉时才改，不为整理而重构 |
| 鲁棒性 | 配置类型错误、换行热词、极短/损坏输入、生成中途的草稿 |
| 失败与降级 | 历史关闭、模型未就绪、纪要保存失败、设备与更新校验（更新校验沿用已有强制 SHA-256） |
| 界面 | `QT_QPA_PLATFORM=offscreen` 打开主窗口各页、转写条、托盘菜单、准备页、历史冲突框，截图在 `build/qa-20261022/` |

## 发现与处置

状态：**修** = 已确认并修复，并有回归用例。严重度 P1 会让应用起不来或弄反用户的开关；P2 会让用户误判当前正在发生的事；P3 是说法不一致或边界输入。

| # | 级别 | 维度 | 问题 | 复现 | 处置 |
| --- | --- | --- | --- | --- | --- |
| F1 | P1 | 数据安全 / 失败路径 | 配置里该是数字或布尔的字段写成字符串、`null` 或小数时，启动在 `int()` 处崩溃。字符串 `"false"` 在 Python 里为真，历史和开机自启会显示成开启 | 临时 `config.json` 写入 `audio.mic_device_index: "auto"`、`history.enabled: "false"` 等，加载后对设备索引做 `int()` | **修**。读取时按默认值的类型收回：`"false"` / `0` 为关，`"8"` 为整数，无法识别的值回到默认。不把原值写入日志。`tests/test_config.py::test_mistyped_scalars_do_not_crash_startup_and_false_stays_false` |
| F2 | P2 | 功能正确性 / 清晰性 | 纪要正在生成时，若本页还开着未保存的草稿，生成会被取消以保住草稿，但状态栏接着被写成「正在生成纪要…」。草稿写盘失败时，失败说明也会被盖掉 | 会议页进入编辑，改动正文，直接调用开始生成 | **修**。取消之后改写状态：保存成功为「已保留正在编辑的纪要，未用生成结果覆盖。」；保存失败仍提示尚未保存。生成已经不在进行时，不再把进度文案写回去。`tests/test_meeting_ux.py` 中 `test_an_open_draft_stops_generation_before_it_replaces_the_notes`、`test_a_draft_that_cannot_be_saved_is_not_reported_as_still_generating` |
| F3 | P3 | 清晰性 | 取消「原文整理」时状态写成「上一版纪要保持不变」；纪要生成中的提示也一律写「整理进行中」 | 对精整模板点取消；分别看纪要与精整的进行中提示 | **修**。取消文案跟当前结果称呼走（纪要 / 精整正文）。进行中提示分别是「生成进行中」「整理进行中」。`test_cancelling_a_refinement_names_the_refinement`、`test_generation_locks_edit_template_and_restore_then_unlocks_on_failure`、`test_an_unchanged_editor_still_lets_generation_start` |
| F4 | P3 | 鲁棒性 | 热词字符串按逗号分隔。词里的换行会原样送进解码器，一行被拆成两段 | `format_hotwords([{"term": "甲\n乙"}])` | **修**。逗号和各种空白都收成一个空格，过长的词仍丢弃。`tests/test_speech_recognizer.py` 的 `test_format_hotwords_uses_terms_only_and_dedups` |
| F5 | P3 | 一致性 | 设置里的选项是「输入当前光标」「仅保存到历史」，侧栏、关于页和快捷键说明却写「粘贴到光标」「仅记录历史」。历史关闭时转写条写「改回粘贴」 | 对照 `dictation_hints` 与通用页「结果去向」；窄窗截图里侧栏为「粘贴到光标」，同页说明为「输入当前光标」 | **修**。侧栏、关于页、快捷键说明和转写条改用设置里的说法。`tests/test_about_ux.py`、`tests/test_app_history_wiring.py::test_history_only_output_warns_when_history_is_disabled`。README 常见问题里的旧说法已改成「仅保存到历史」 |
| F6 | P3 | 一致性 | 现行规格写：升级时明确的结果去向只留给当时的录制方式，另一种回到自动。代码、测试、README 和 v2.2.16 发布说明都是两种模式一起保留，避免没选中的那种开始往光标输入 | 读 `openspec/specs/dictation-mode-defaults/spec.md` 与 `tests/test_config_audio.py` 的迁移用例、README「升级前已经选定的固定去向会同时用于两种模式」 | **修规格，不改升级行为**。现行规格改为两种模式都保留该明确选择。归档里的立项原文不动，见未处理项 |

## 误报与有意不改

| 项 | 为什么不是本轮要改的问题 |
| --- | --- |
| 侧栏「正在启动…」看起来被截断 | 这是状态原文（省略号），不是窄栏把字裁掉 |
| 引擎页按钮「更改存储…」 | 按钮文字本身带省略号，表示还会弹出选择，不是挤掉了「位置」 |
| 转写条长错误只显示一行并省略 | 完整句子在工具提示里；条的高度是固定的 |
| 设备还没打开就松开，提示「录音过短」 | 既有用例把这次松开和「按得太短」看成同一件事，提示用户按住更久。日志里另有「设备尚未打开」 |
| 引擎页标题「公共识别辅助模型」 | README 仍用「公共识别」指这组辅助模型。真正的入口说明已写「通用 → 识别 → 高级识别设置」，没有再指向一个不存在的页面 |
| 说话人相似度 0.30、单人会话不新增编号 | 第二轮已用视频和两场标注会议验证。本轮随机向量没有打出崩溃或与规则矛盾的归属，没有新证据去改阈值 |
| 手写 200 条术语的替换约 66 毫秒 | 设置页最多保存 50 条、每条 20 字。不再加一道会改变手改配置文件行为的上限 |
| 窄窗六页、准备页、托盘、历史冲突框 | 880×580 与 1280×800、深浅色没有横向滚动条，也没有无名的可见按钮。会议长标题在列表里省略，详情里可以读完 |
