# SayInk 页面一致性复核（2026-10-19）

本次对历史、会议、通用、引擎、AI 服务、关于六个页面进行同尺寸原生渲染对比，并修正发现的差异。延续现有品牌、导航顺序和深浅主题；保留此前纪要模板管理的改动。

## 发现与处理

| 维度 | 发现 | 本次处理 |
| --- | --- | --- |
| 内容宽度 | 关于页上限 760，其他设置页为 900；大窗口切页时边界跳动 | 四个设置页共用 900 逻辑像素上限；相同窗口下内容左右边界一致 |
| 页面类型 | 历史和会议需要列表及详情，设置页是单列文档 | 保持工作区充分使用窗口宽度；设置文档统一居中；长文阅读行宽上限 720 |
| 页面边距 | 设置页额外宿主边距使默认窗口左边缘比工作区多缩进 6 | 统一可用宽度下的左侧起点；保留固定滚动条预留区 |
| 标题位置 | 字号相同，但历史、会议、设置标题的顶端和高度不同 | 六页共用标题组件、34 高标题行、20px / 700 字重及垂直居中 |
| 字体与层级 | 全局中文字体已统一；润色示例标题会在换肤后从 14 变成 16 | 保留微软雅黑优先的字体解析；示例标题与分组标题统一，重绘不改变字号或尺寸 |
| 正文阅读 | 历史正文 15px，会议正文 14px；长文行宽规则不同 | 保存内容共用 15px、160% 行高和 720 行宽上限；编辑区域可使用可用宽度 |
| 表单高度 | 普通文本、下拉、数字和快捷键控件各自使用不同高度与内边距 | 单行表单控件统一外部高度 40；焦点边框通过内边距补偿保持原尺寸 |
| 搜索与分栏 | 历史、会议搜索高度 40 / 46；初始列表宽度和伸缩比例不同 | 搜索高度均为 40；列表最小宽度、详情最小宽度、初始分栏与伸缩比例共用规则，仍可拖动调整 |
| 操作按钮 | 历史复制操作使用较高的按钮，会议操作使用紧凑按钮 | 复制操作使用共同的小型按钮规格，保留主操作与次操作的颜色层级 |
| 背景与填充 | 设置宿主容器的裸透明样式影响后代，覆盖输入框底色 | 透明样式限定到指定容器；表单文字框、下拉框、数字框共用输入底色 |
| 悬停与选中 | 深色主题二者底色完全相同，截图看起来像两项选中 | 悬停透明度降至 3%，选中保留 6% 和粗体；实际导航始终只有当前页选中 |
| 分组间距 | 页面构建器各有覆盖值，分组标题初建和换肤后留白不同 | 设置页边距和 16 分组间距集中定义；分组标题初建、换肤使用同一样式 |
| 配色与对比 | 正文、辅助文字、链接已有清楚的语义色 | 保留现有层级；正文和辅助文字对页面底色的最低对比度为 4.97:1，链接最低 5.17:1 |
| 圆角与边框 | 卡片、输入、按钮各自有明确层级 | 保持同类控件统一；卡片 10、输入 8、小按钮 6；键盘焦点共用主题焦点色 |
| 内容长度与滚动 | 各页内容数量不同，展开路径或高级设置会改变高度 | 高度由内容决定，超出后纵向滚动；滚动条出现或隐藏时保持列宽及水平位置 |
| 长文字与空态 | 会议空提示、更新错误、设备说明和文件位置有换行需求；长更新错误还会压矮关于页快捷链接 | 检查窄窗口、长更新状态、展开内容和纪要空态；为快捷链接保留足够的最小高度；保留列表省略及完整提示的语义 |
| 键盘与编辑 | 页面切换、焦点框和编辑撤销需要稳定 | 检查 Tab / 快捷键、单一导航选中、聚焦尺寸；编辑时调整窗口不会占用下一步文字撤销 |

## 统一规格

- 四个设置页：内容文档最大宽度 900，内边距 18 / 12 / 18 / 14，分组间距 16。
- 两个工作区：外边距 24 / 20 / 24 / 20，列表最小 240，详情最小 380，初始分栏 250 / 490，同一伸缩策略。
- 文字：页面标题 20，分组和正文界面文字 14，辅助说明 13，短元数据 12，保存的阅读正文 15。字体家族共用全局解析。
- 单行表单与搜索框：40 高。小型动作按钮：32 内容高度及边框。焦点前后外部尺寸一致。
- 页面高度随内容变化。卡片内容、状态行与滚动位置服务各自任务。

以上均为 Qt 逻辑像素；显示缩放由 Qt 统一处理。

## 验证与证据

复现工具：[capture_ui_consistency.py](../tools/capture_ui_consistency.py)。使用临时配置与虚构历史，屏蔽凭据、开机自启注册表、音频设备枚举和模型可用性；不联网、不录音、不加载识别模型。

验证矩阵：960×640、1560×750、880×580，深浅两种主题，100% / 150% / 200% 缩放。附加状态包括展开文件位置、长更新失败说明、展开高级设置、开始会议卡片、原文精整空态。检查换行标签及按钮文字容纳情况。

自动回归见 [test_ui_consistency.py](../tests/test_ui_consistency.py)，覆盖共同列宽和标题、分栏、输入底色、聚焦尺寸、悬停辨识、换肤稳定、展开滚动和阅读行宽，以及编辑撤销。

验证结果：相关回归共覆盖 398 个独立测试，全部通过（分批执行，后续修改补跑受影响检查）。三种缩放共 138 张原生预览；换行标签和按钮文字检查均为 0 问题。Ruff 与本轮修改的差异空白检查通过。
