# SayInk 桌面 UX/UI 重设计

## 设计判断

面向日常高频语音输入的原生桌面工作台。保留 SayInk 品牌、五项导航和托盘工作方式，以清晰的任务顺序、可读的中文、可预测的反馈降低操作负担。

设计刻度：DESIGN_VARIANCE 3 / MOTION_INTENSITY 2 / VISUAL_DENSITY 5。
本项目是 PyQt6 桌面产品；网页着陆页的布局、字体包、SEO 和动画要求不适用。

## 改版前审查

依据当前源代码、原生页面截图和现有测试进行启发式审查，尚未开展真实用户可用性实验。

| 问题 | 对用户的影响 | 设计响应 |
| --- | --- | --- |
| 持续转写卡写“按一次开始，再按一次结束”，与实际逻辑冲突 | 用户可能以为已停止，实际仍在录音 | 所有入口使用按住启动、Esc/结束停止的规则；名称与侧栏一致；提示随模式变化 |
| 主导航 12px、29px 高且禁用焦点 | 辨识困难，键盘用户无法到达页面 | 14px 导航、40px 行高、焦点环与快捷键 |
| 设置页直接从分组开始，无页面标题 | 切换后需要重新定位 | 各页有一致的标题、用途说明；设置保留即时保存 |
| 配置窗口收到运行状态却不展示 | 不知道模型是否已能使用 | 侧栏持久显示真实运行状态与当前输入方式 |
| 选择卡仅淡底区分，隐藏原生 radio | 选中不明确，辅助技术语义不足 | 显式原生单选标识、文字说明和键盘焦点 |
| 历史左右等宽且工具挤在详情标题旁 | 长文阅读空间不足 | 可调分栏，阅读区优先，工具独立一行 |
| 历史预览换行而行高固定 | 长内容重叠或被裁切 | 单行按实际宽度省略，完整内容保留在详情和 tooltip |
| 清空历史是底部全宽红按钮 | 高频阅读路径被低频危险操作干扰 | 底部小型次要操作，保留确认与删除撤销 |
| 听写条在无监听时仍显示结束 | 操作与状态不匹配 | 仅整场监听期间显示结束；保留非抢焦点行为 |
| 测音失败弹窗且缺少恢复路径 | 打断配置，错误消失后无据可查 | 就地反馈、状态文案与设备恢复入口 |

## 信息架构与任务顺序

- 历史：搜索 → 选择会话 → 阅读 → 复制/导出；删除为次要操作。
- 通用：了解触发方式 → 设定快捷键 → 选择声音 → 测试 → 调整偏好。
- 引擎：当前配置 → 模型存储 → 可用模型；区分“已下载”与“已载入”。
- 润色：了解输出变化 → 开启 → 配置连接 → 测试；说明文本会交给所配服务处理。
- 关于：版本、当前配置、文件位置及使用提示。

## 人因与交互约束

- 识别优于回忆：把开始/停止方式显示在使用位置；副标题描述用户任务。
- 选择状态由标识、字重和背景共同表达，不只依靠颜色。
- 页面主动作保持明确；常用动作靠近内容，破坏性动作与之拉开距离。
- 键盘支持 Tab、Space/Enter、原生单选方向键；Ctrl+1…5 切页、Ctrl+F 搜索历史、Ctrl+W 收到托盘。
- 深浅主题共用语义令牌；蓝色仅用于焦点与链接，绿/红/琥珀表示状态。
- Qt 样式表只能指定单一字体。运行时优先微软雅黑，跳过不能覆盖常用中文的西文字体，避免真机选中 Segoe UI Variable 后缺字。
- 原生缩放、可调整窗口与分栏；避免无限拉长设置行，保留纵向滚动。
- 数据、快捷键、录音、模型下载及转写链路沿用现有实现。
- 空历史区分未开启、尚无会话和搜索无结果；关闭时提供设置入口。
- 最近会话分批加载，超过 50 场可继续查看；刷新不重置当前选中和搜索。
- 模型下载立即禁用重复点击，失败原因与“重试”保留在对应模型卡内。

## 验证

基线：648 项通过。HTML 原型归档测试已改为确认旧 HTML 表面已退役。
预览工具：`py -3.10 tools/capture_ui.py --output build/ux-preview`，使用隔离配置和明确的示例会话，不读取用户历史、不打开麦克风、不发起网络请求。
验收包含深浅主题五页截图、长文本/无结果/关闭润色、键盘导航、模式说明、运行状态更新、历史复制与删除撤销等回归。
