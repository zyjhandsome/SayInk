# 说话人拆人 / 并人标定

会议纪要会按说话人写发言摘要和待办负责人。聚类阈值还没有用真人会议标定。
在本文件的结果表填上数字之前，对外口径保持 README 的「实验性」：设置里写明
不验证人物身份，会议页写明姓名来自手动命名。

「（待核对）」只标记文字稿里找不到的日期和金额，挡不住「同一个人被拆成两个编号」。
所以这张表是单独的尺子，不能用纪要里有没有「待核对」来代替。

## 标什么

至少 **3 段**已经结束的双人以上会议。音频留在仓库外，脱敏后再标注。
每一行是文字稿里的**一段**（一次识别切片），不是纪要里的一节。

```
序号	真人	预测
1	甲	1
2	甲	1
3	乙	2
```

- **真人**：听录音填写的人。同一个人全程用同一个代号。看不清就不要猜，删掉这一行。
- **预测**：SayInk 给出的说话人编号（改名之前的编号）。手动改名、单段纠正之后的结果不要拿来填这张表，那测的是人手，不是聚类。

用 CAM++ 跑一场，再把说话人增强关掉用频谱法跑同一段录音，各填一份。两份都要有，才能判断嵌入模型是否比频谱法少拆、少并。

## 怎么算

`tools/speaker_eval.py` 只读这张表，不读音频，也不加载声纹模型。

```powershell
py -3.10 tools/speaker_eval.py D:\bench\meeting-01-campplus.tsv
```

- **拆人**：某个真人的各段用了多于一个预测编号。拆人率 = 被拆的真人人数 / 真人人数。
- **并人**：某个预测编号下面有多于一个真人。并人率 = 这种编号的个数 / 预测编号个数。
- 一个人对应一个编号、不同人编号不同：两项都是 0。
- 空表没有比率。

设计成功标准 3 要求：嵌入模型的拆人率和并人率都明显低于同一批录音上的频谱法。
「明显低于」在有第一批数字之前不改写成某个百分比。
